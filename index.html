🚀 GitHub Pages Deployment & Git Workflow

How to commit, push, pull, and deploy this interactive RepoGraph web app to GitHub Pages.

Step 1: Commit and Push to Your GitHub Repository

git init git add . git commit -m "feat: RepoGraph Interactive Architecture Studio" git branch -M main git remote add origin https://github.com/<your-username>/RepoGraph.git git push -u origin main

Step 2: Enable Automated GitHub Pages Deployment

1. Open your repository on GitHub → Settings → Pages.

2. Under Build and deployment > Source, choose GitHub Actions.

3. That's it! The included .github/workflows/deploy.yml workflow automatically builds and deploys your site to:

https://<your-username>.github.io/RepoGraph/

Step 3: Daily Pull & Push Updates

Whenever you update code locally or scan new repos:

# Pull latest changes git pull origin main # Re-scan local repo python repograph.py demo_project # Commit & push to auto-update GitHub Pages git add . git commit -m "update: architecture blueprint" git push origin main
